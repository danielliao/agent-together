    CONNECT YOUR AGENTS

    一起吃，
    先让各自的 Agent 到场。

    1. 各自启动 Agent sidecar

      每个成员在自己的本机连接麦当劳 MCP，凭证仅保存在自己本机的内存中。

    2. 分享最少必要的信息

      只共享近期偏好摘要、本次需求和可用权益，不分享完整订单、地址或 Token。

    3. 主人亲自确认

      真实报价生成后，每位成员从自己的 Agent 确认同一版方案。成员未连接、未确认时，不允许真实下单。

    当前页面是发起人视角。演示中的批准、下单和支付均为模拟，无法替代真实授权或付款。
